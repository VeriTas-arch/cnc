# Computational neuroscience Codes (CNC)

This repository contains codes for basic computational neuroscience tutorials, which is also used in relevant courses. Feel free to contribute to this repository.

## Included Topics

- Single neuron model, specifically the Hodgkin-Huxley model
- Reduced single neuron models
- Synapse models
- CANN
- Amari-Hopfield network
- Decision making models
- Reservoir computing
- Recurrent neural networks
- Working memory models
